# Changelog

## [1.0.0] - 2026-07-10

### Added
- Initial release of rb-library.
- Web interface to browse the PDF library from index.html.
- Support for filtering by category, language, and type.
- Search functionality by document name or filename.
- Main library metadata in library.json.
- Optional custom library metadata in custom-library.json.
- Python script update.py to scan PDF folders and add new entries interactively.
- Support for linking PDFs from the main folder and the custom folder.

### Notes
- This is the initial version of the project and serves as the starting point for future enhancements.
